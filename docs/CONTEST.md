# Сдача «Цифрового деканата»

Режим конкурса использует вымышленные записи и маркировку прототипа.
Публичная ссылка стенда — [Цифровой деканат](https://three-agents-studio.serveousercontent.com/).
Ссылка ведёт на релиз только после его развёртывания. В бесплатном режиме может
появиться промежуточная страница Serveo с кнопкой Continue to Site.

## Показ за три минуты

1. Войти как `jury_student_a`. На главной видны пары «Сегодня по МСК».
   В «Учёбе» открыть неделю, проверить время, аудиторию, преподавателя и скачать
   календарь `.ics`. Внизу видны задание и оценка.
2. В «Заявках» подать справку об обучении с коротким вымышленным комментарием.
3. В отдельном браузерном профиле войти как `jury_deanery`. Взять заявку в работу,
   отметить её готовой и оставить пояснение о порядке выдачи. Опубликовать
   объявление факультета, если требуется показать рассылку.
4. Снова открыть кабинет первого студента. В «Заявках» развернуть историю из трёх
   статусов. В «Уведомлениях» открыть ответ, отметить прочитанным и обновить вкладку.
5. В приватном окне войти как `jury_student_b`: другой факультет, расписание и
   заявка. Ответ по справке и объявление первого факультета отсутствуют.
   `jury_teacher` позволяет показать добавление работы и выставление результата.

## Подготовка Mac к показу

1. Откройте отдельную копию проверенного релизного коммита. Используйте Node
   из `.nvmrc`, действующее Python-окружение и работающий Docker Desktop.
   Выполните `npm ci && npm run build` в `frontend`.
2. Из корня релиза запустите `python scripts/prepare_contest_preview.py --database-env /путь/к/.env`.
   Скрипт сохраняет архив PostgreSQL, применяет аддитивные миграции и создаёт
   четыре изолированных аккаунта. Повтор использует существующий файл доступа
   и не перезаписывает пароли. При другом имени контейнера передайте
   `--database-container`. Новый файл `.team-preview/jury-access.json`
   имеет права 600, хранится на Mac. Передайте пароли жюри закрытым каналом.
3. Сохраните прежний ключ сессий `.team-preview/secret.key` и `known_hosts`
   от того же стенда в новой рабочей копии с правами 600. Остановите старый
   просмотр и запустите прежний Serveo hostname из папки релиза по
   [инструкции командного просмотра](TEAM_PREVIEW.md).
4. Проверьте `/health/ready/` и весь сценарий выше на публичной ссылке.
   На iOS Safari и Android Chrome проверьте вход, навигацию, форму заявки и
   отображение от 360 px. Повторите на домашнем и мобильном интернете в России
   без VPN. Сопоставьте публичную сборку с локальной через `scripts/check_preview.py`.
5. До 28 ноября владелец стенда оставляет Mac с открытой крышкой, в сети и с
   запущенными PostgreSQL и launcher. При разрыве SSH launcher переподключается.
   Если Mac выключен или провайдер недоступен, потребуется восстановить стенд.
   Согласуйте резервного ответственного и передайте ему сценарий, ссылку и backup.

## Архив и восстановление

CI восстанавливает архив с вымышленными данными PostgreSQL в отдельную БД и
проверяет роли, расписание, оценки, историю заявок, объявления и миграции.
Перед показом храните свежий закрытый архив в надёжном месте. Для репетиции
восстановите его в **новую пустую** БД, создаваемую вручную под отдельным именем,
и направьте проверочный экземпляр Django на неё. Проверьте `migrate --check`,
два входа и историю заявки. Команды для контейнера PostgreSQL, с подстановкой
своих имён и пользователя:

```sh
docker exec main-project-db-1 createdb -U deanery deanery_rehearsal
docker exec -i main-project-db-1 pg_restore -U deanery --exit-on-error \
  -d deanery_rehearsal < /полный/путь/к/проверенному.dump
```

При сбое приложения вернитесь к прежней проверенной папке и запустите её по
тому же адресу. Схема релиза добавляет таблицы, поэтому прежняя версия может
читать уже существующие данные без отката миграций. При сбое PostgreSQL
восстановите архив в другую БД и переключите `.env` после проверки этой копии.
Файлы доступа и секреты хранятся отдельно от Git и CI-артефактов.

Inter распространяется по SIL OFL 1.1, копия лицензии лежит в
`backend/core/static/core/fonts/OFL.txt`. MIT-лицензия исходников picomatch
сохранена в `frontend/vendor/picomatch/LICENSE`. В интерфейсе используется
собственный знак проекта.
